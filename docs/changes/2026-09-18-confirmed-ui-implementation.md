# 引用 UI 实施记录（2026-09-18）

按用户确认方案实施，源码与本地构建完成，未发布或安装到运行实例。

- 保留引用数量入口的悬停/点击展开逻辑。
- 单层编辑面板；黑圆白勾保存、细线删除/断链/返回原文图标；来源标题优先。
- Enter 提交、Shift+Enter 换行、输入法选字不提交；点击外部或切换引用撤销未提交修改；失败保留输入。
- 编辑当前会话引用时自动定位原文并保留输入焦点；其他来源只在主动跳转时导航。
- Core 自己从待发送与已读取的已发送引用记录绘制灰色高亮；CSS Highlight 不改写消息 DOM，正文重挂载时重建范围，移除引用清理对应范围，不删除其他 owner 的高亮。
- 新增 DSH 消息来源适配器。定位使用会话投影的稳定节点 ID；未加载的原文会报告定位失败，不猜测替代位置。
