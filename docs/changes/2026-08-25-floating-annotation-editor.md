# 浮动注释编辑器 UI 修复记录

## 问题

注释详情原先采用全屏遮罩和居中大卡片。打开“补充注解”后会遮挡整个 DSH，会话内容无法继续查看或操作；多条注释全部纵向展开时窗口过长，原文、来源和输入区域也缺少视觉层级。

## 修改前

- `ReferenceDialog` 通过覆盖整个页面的半透明 backdrop 承载模态窗口。
- 所有注释同时渲染为大卡片，内容越多占用越高。
- 补充注解使用浏览器默认 `textarea`，没有占位提示、聚焦状态或保存提示。
- 详情操作按钮使用浏览器默认外观。

## 修改后

- `ReferenceDialog` 改为右上方非模态浮窗；浮窗之外不拦截鼠标，DSH 主界面仍可操作。
- 多条注释使用紧凑编号切换，一次只显示一条详情，原有稳定编号和引用身份不变。
- 来源、引用原文、补充说明和操作区分层展示；引用原文使用轻量引用块。
- 补充说明输入框增加柔和底色、圆角、聚焦描边、占位文案和“失焦时自动保存”提示。
- 支持 `Escape` 关闭；移动端退化为底部浮动卡片，不恢复全屏遮罩。

## 不变边界

- 不修改 pending/sent 注释状态、删除顺延编号、会话持久化、模型上下文或系统提示词。
- Sidechat 与 Obsidian 引用继续通过 `dsh-annotation-core` 的同一界面 seam 使用该浮窗，不复制第二套实现。
- 已发送注释仍只读，只保留重新添加、来源操作和失败回链重试。
