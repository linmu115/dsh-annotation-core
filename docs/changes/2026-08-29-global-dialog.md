# Annotation Core 0.2.1：引用详情浮窗改为 Core 单例

## 问题

主会话输入框与 Sidechat 会同时创建共享 Composer binding。旧实现让每个 binding
都渲染同一个引用详情控制器，因此打开详情时会出现两个重叠浮窗；历史中的注释节点
也可能继续增加重复实例。

## 修改

- Annotation Core 在客户端启动时只挂载一个全局详情浮窗。
- 输入框与会话节点只渲染引用栏或已发送注释节点，不再各自携带浮窗。
- 浮窗根据当前引用集合的 `sessionId` 选择远程会话，更新说明、删除、复用与重试回链
  都路由到实际拥有该引用的会话。

## 验证

- Core 全部单元测试、构建和打包通过。
- 同时打开主会话与 Sidechat 后，页面只存在一个详情浮窗；Obsidian 引用仍可打开来源。
