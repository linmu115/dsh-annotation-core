# 0.3.10-dev.1

用可选的 inputAcceptance 提供方契约替代 M5 原型新增的内核 preview、readInputAcceptance、readExecutionState 和 executor-tool-bridge 依赖。

普通 DSH 输入按原生用户消息和公开 flush 完成结算；Codex 输入由配套插件提供保存的原生接收回执。通知订阅等待服务就绪，模型还在运行时即可完成引用结算。未确认输入不重放，已删除引用不因恢复而复活。

包移除实验性官方同名桥接依赖及开发工作树链接。`node scripts/build-official.mjs` 在隔离依赖目录执行类型检查和构建。实际官方 RC1 profile 的组合验证在 dsh-codex-runtime 仓库的 R2 验证脚本中，界面及 Obsidian 往返仍待用户验收。
