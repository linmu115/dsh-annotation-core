# 跨会话选择浮窗对齐 DSH 主题

跨会话引用选择器原先使用固定深色底色和浏览器默认按钮，在 DSH 浅色页面内显得突兀。本次将浮窗改为读取 DSH 的背景、文字、遮罩、阴影、悬停和滚动条主题变量，使浅色、深色与窄窗口显示一致。

工作区与会话层级新增当前位置和步骤提示；长标题支持两行显示；列表、加载、空结果及错误提示使用独立样式。保留现有列表读取、分页、返回、选择会话、关闭和引用写入流程，错误正文继续展示后端返回内容。

修改范围：

- `src/client/cross-session-picker.tsx`：浮窗展示结构、图标和说明。
- `src/client/styles.css`：仅新增 `.dshCrossSession*` 作用域样式。
- `tests/cross-session-picker.test.tsx`：适配返回按钮的新文字结构。

验证：

- TypeScript 类型检查通过。
- 现有选择器测试 2/2 通过，包括分页、失败后保留选区、目标会话跳转与草稿不变。
- 用实际组件与已安装 DSH 官方主题生成独立预览；浅色工作区、深色会话、错误状态和 390 × 640 窄窗口均无越界、无浏览器运行错误，并已检查截图。

本次按照用户“先排错，先不改功能，同时优化浮窗 UI”的要求进行。引用目标竞争与 Maintenance 扩展版本兼容错误仅记录为诊断结果，没有修改相关功能代码。本提交未变更版本或发布清单，也未部署或重启正在排错的 RC2 副本；UI 生效需后续部署。
