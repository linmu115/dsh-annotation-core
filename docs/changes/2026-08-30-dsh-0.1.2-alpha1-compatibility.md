# 0.3.4 — DSH 0.1.2-alpha.1 compatibility record

## Upstream breaking changes

- The monolithic `dsh-client-runtime` surface was removed.
- Conversation extensions and rendered Chat data moved to native `uiConversation` registries and Chat targets.
- Alpha.1 folds completed Turn Process nodes differently, which can hide plugin nodes unless their projection is kept outside the folded process seat.

## Annotation Core changes

- Inject `api-session-controller`, `ui-conversation`, `ui-chat`, and `ui-input-trigger` directly.
- Register annotation node definitions through `uiConversation.events` and the native Chat node data registry.
- Keep committed reference bubbles visible after an answer completes instead of allowing the Turn Process fold to hide them.
- Publish the Core capability at the top-level client scope for separately loaded Sidechat and Sticker Board consumers.
- Add Host-side reference deletion so tombstones and Obsidian cleanup continue when no DSH browser page is open.
- Use optional open peers and capability negotiation rather than a DSH version admission gate.

The implementation targets alpha.1 directly and does not retain the removed RC2 Client Runtime adapter.
