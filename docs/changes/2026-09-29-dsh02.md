# DSH 0.2.0-rc.2 maintenance

Migrates tool-result capture and replacement to top-level tool messages, preserves pairing/source/raw history, adopts serial agent-created callback and codec factories, and prices actual image blocks. Public Annotation SDK and wire contracts stay unchanged. The optional managed-host contextProvider remains supported; stock host does not expose that optional extension.

Initial candidate stage (2026-09-29): validated against the actual Launcher 0.2.0-rc.2 distribution in isolated worktrees. Candidate versions use dsh02.1 and have not been published or installed into a real profile/Vault. Unit/integration, type and package checks are recorded in the maintenance report. Native UI layout, scroll, resize, activation, reload and real Obsidian interactions remain unaccepted pending the coordinated browser acceptance run.

## Installed acceptance update (2026-09-30)

Installed version: `0.3.12-dsh02.2`. Uses the official main-view session ownership and workspace navigation APIs. The coordinated RC2 acceptance verified ordinary selection-to-sticker creation, first save, native sidebar display, reload retention and matching Vault session-note synchronization. One real V3 history sample passed conversion and cold reload; this is not full-history migration or an Annotation capture/backlink-click acceptance.

The target remains on the exact Launcher DSH 0.2.0-rc.2 baseline. Session Maintenance was reversibly isolated for this plugin acceptance; this does not claim that the external engine or managed lifecycle was repaired. The frozen installed artifacts remain unchanged. This source update adds delivery documentation and does not itself publish a registry package or GitHub Release.
