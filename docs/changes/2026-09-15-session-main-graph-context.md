# 会话主干图的引用接续与披露回执

版本：0.3.12-rc2.8；宿主：DSH 0.1.5-rc.2。

## 行为

- 新增 `session-main-graph-v2` 客户端能力。ThoughtDAG 从节点进入真实会话时，通过 `prepareGraphReferences` 恢复该节点已保存的入向引用。复用原引用、来源版本和完整回复截止位置，不重新捕获最新来源，不自动发送。
- 同一目标/引用批次的进行中请求合并，已有引用不重复附加；异步准备中若用户切换会话则停止写入。继续保留已有正文、附件及合法引用。
- `describeGraphReference` 经 Agent 作用域传入 Maintenance，只允许当前目标关联且未撤销的固定引用。已发送关系缺少本地提交记录时明确要求恢复，不能把旧引用重新绑定到新的用户轮次。
- 引用变化发出本窗口事件，供来源高亮和蓝色跳转符号刷新；跨窗口刷新仍由相应插件按权威状态完成。
- 首轮来源问答和后续读取/搜索使用独立请求身份。Maintenance 先记录“已准备”，初始提交经持久提交链确认、工具输出通过预算与取消检查后，再确认交付。取消或失败记录为失败，不声明模型已读取或理解来源。
- 单次/累计预算仍由原机制控制，工具只读固定上游，不启动来源 Agent。

## 验证

- TypeScript 类型检查及插件构建通过。
- 33 个测试文件、187 项测试通过，包括固定引用恢复、重复操作、切换目标、撤销/丢失提交、初始材料、搜索分页及交付取消。
- 安装、真实宿主组合探针与副本交互结果在本次 Maintenance 发布报告记录；本文不把单元测试等同于真实模型回答验收。
