# Annotation Core 0.3.7 - DSH 0.1.2-rc.1 session migration

DSH 0.1.2-rc.1 removed the public `Session.events` array and introduced
demand-oriented immutable session snapshots. Event positions are now branded
as `SessionSeq` rather than interchangeable plain numbers.

Annotation Core now reconciles submissions from `Session.snapshotEvents()` and
keeps the observed `SessionSeq` intact when reconstructing an annotation
context event. No Alpha2 fallback is retained.

This release does not change the public Core Host API, deletion outbox,
submission durability barrier, prompt contents, or conversation-node
visibility. Those contracts remain regression gates for the RC1 profile.
