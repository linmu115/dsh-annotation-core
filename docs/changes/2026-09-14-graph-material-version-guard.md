# 画布材料捕获的来源版本保护

日期：2026-09-14。修复材料预览后来源重生成或改变、引用可能悄悄捕获新版本的问题。

`DshMessageCapture` 增加可选 `expectedSourceVersionId`。图客户端将预览时的版本作为前置条件传入；Annotation host 在调用 Maintenance 原子捕获接口时透传，并检查返回回执版本。并发幂等引用操作的来源比较也包含版本，不能把两个不同版本请求当作同一操作。

真正的版本检查发生在 Maintenance 创建引用的写入协调期间。前端无需另行执行“先检查后创建”的非原子流程。版本失配产生可解释失败，草稿与旧来源不被自动替换。普通划选没有指定版本时沿用既有行为。

验证：上游生命周期与跨会话选择器两个文件共 13 项测试通过，类型检查通过；新增测试覆盖版本字段校验、host 透传与错误回执拒绝。Maintenance 对应测试覆盖原子拒绝且不新增对象。此提交未发布或部署。
