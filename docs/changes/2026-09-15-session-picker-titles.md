# 跨会话引用选择器名称修复

Maintenance 注册原生会话时可能保留 `DSH session <id>` 这样的初始标题，而 DSH 会话栏已从原生日志得到新的可读标题。原选择器直接显示登记标题，使用户无法识别目标。

选择器现在保留 Maintenance 返回的工作区、允许访问的会话 ID、顺序和分页，只修正会话行的显示名称。优先使用 DSH `sessions.list` 中的正式标题，其次使用 Maintenance 的可读标题，再使用 DSH 的显示名称。无可读元数据时显示“未命名会话”，不把内部投影标识冒充名称。工作区名称不受影响，选择操作仍使用原来的 ID。

这一变更不请求或打开完整历史，不更改存储中的会话标题，不增加列表轮询，不改变引用版本或截止位置。重新打开选择器时读取当前标题，因此改名会在下次选择时生效。

回归覆盖：登记名称是 ID 而原生标题存在；同 ID 的目标导航不变；工作区不被会话标题覆盖；冷会话名称回退；列表阶段不额外 refresh；分页、失败重试以及目标正文和附件保留。

验证：TypeScript 检查和正式构建通过；38 个测试文件、240 条测试通过。该记录只证明源码及包构建，副本安装另以部署回执核对。
