# dsh-annotation-core

Shared annotation state, native-submission adapter, prompt envelope, and Codex-style annotation UI for DeepSeek Harness plugins.

The implementation targets the official DSH `0.1.1-rc.2` `web` profile and contains no EAC-specific behavior. The current development branch includes the versioned protocol, immutable reference state machine, durable Host aggregate, Agent-scoped Typert boundary, and public Host/Client service contracts. Submission, prompt projection, and UI land in the later implementation-plan tasks.
